# firestore_builder example

A minimal Flutter app that uses the code generated by `firestore_builder`.
It doubles as the compile check of the generator: everything under
`lib/firestore/` is generated from `firestore_builder_config.yaml`, and
`lib/main.dart` shows how that code is used from a widget tree.

What it shows:

- streaming the `teams` collection through the generated Riverpod provider
  (`teamCollectionProvider`)
- adding a document with the generated query service (`addTeam`)
- updating single fields with the `UpdatedValue` wrapper, including an enum
  field (`UpdatedValueTeamSize`) and a Firestore `FieldValue`
- deleting a document (`deleteTeam`)

## Regenerate and check

From this folder:

```sh
dart run firestore_builder
dart run build_runner build --delete-conflicting-outputs
flutter analyze
```

`generate_code.sh` runs the first two commands. From the package root,
`tool/check_example.sh` runs all of them and is meant to be run before
publishing.

## Running it against Firebase

The example is not wired to a Firebase project and ships without platform
folders. To try it live, run `flutter create . --platforms=ios,android` to
add the platform folders, then `flutterfire configure`, and pass
`options: DefaultFirebaseOptions.currentPlatform` to `Firebase.initializeApp`
in `lib/main.dart`.
